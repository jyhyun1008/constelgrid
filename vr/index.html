별자리 메모보드 퀘스트 앱

메모와 웹 창을 내 방 공간에 띄워 두고 별자리처럼 잇는 메타 퀘스트 앱

  • 공간에 띄우는 메모마크다운 메모와 북마크 카드를 원하는 자리에
  • 웹 창로그인, 영상, 음악까지 되는 브라우저 창
  • 키보드와 마우스블루투스 키보드·마우스로 조작, 한글 두벌식 입력
  • 2D 보드와 같은 보드미스키 드라이브로 이 사이트의 보드와 동기화
최신 버전 확인 중…
APK 내려받기

    설치하는 방법

    1. 퀘스트 개발자 모드 켜기 휴대폰의 Meta Horizon 앱 → 기기 → 헤드셋 설정 → 개발자 모드를 켜요. 처음이라면 메타 개발자 사이트에서 개발자 등록(무료)을 먼저 해야 해요.
    2. APK 설치 컴퓨터에 SideQuest를 설치하고, 퀘스트를 USB로 연결한 뒤 내려받은 APK를 SideQuest 창에 끌어다 놓아요. 헤드셋 안에 "USB 디버깅 허용" 창이 뜨면 허용해 주세요.

      adb를 쓸 줄 안다면: adb install -r constelgrid-v버전.apk

    3. 실행 퀘스트 라이브러리의 "알 수 없는 출처"에서 별자리 메모보드를 찾아 실행해요.

    업데이트와 데이터

    새 버전도 같은 방법으로 설치하면 돼요. 기존 앱을 지울 필요 없이 위에 덮어 설치되고, 보드도 그대로 남아요.

    앱의 로고 메뉴 → 동기화에서 미스키에 로그인하면, 이 사이트의 2D 보드와 같은 보드를 저장하고 불러올 수 있어요.

    메타 스토어는 한국 계정의 테스트 참여를 막고 있어서, 지금은 이 페이지에서 직접 설치하는 방식으로 나눠요.
