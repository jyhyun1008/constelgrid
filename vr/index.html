별자리 메모보드 VR

메모들이 나를 둘러싼 별자리처럼 떠 있습니다. 메타 퀘스트 브라우저에서 VR 입장을 누르세요. 2D 보드와 같은 데이터를 사용하므로 어디서 고쳐도 그대로 이어집니다.

2D 보드
조작 방법
  • 트리거(핀치): 메모 선택 · 끌어서 이동 / 빈 하늘을 잡고 끌면 보드 회전
  • 그립: 여러 개 선택 (손 추적은 메뉴의 다중 선택)
  • 썸스틱: 좌우 회전 · 위아래 이동
  • 편집 · 북마크: 잠시 VR에서 나와 키보드로 입력한 뒤 다시 입장
  • PC에서는 드래그로 둘러보기, Shift/우클릭으로 다중 선택, 휠로 위아래 이동
